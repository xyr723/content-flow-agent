# 需求分析

## 背景

创作者经常需要把同一份内容同步发布到公众号、知乎、B 站、小红书、抖音等平台。不同平台对标题、正文结构、标签、图片、视频、封面和语气风格都有不同要求，手动适配成本高。

## 用户痛点

- 同一内容需要反复复制粘贴。
- 不同平台格式不同，容易漏字段。
- 图文和视频素材需要分别整理。
- 标题、标签、简介要按平台重写。
- 多平台发布前缺少统一预览和校验。
- 真实发布容易涉及账号、Cookie 和权限风险。

## 目标用户

- 自媒体创作者。
- 运营人员。
- 视频号和短视频创作者。
- 需要多平台分发内容的小团队。

## MVP 范围

### 必须支持

- 输入原始文本。
- 管理图片和视频素材的结构化信息。
- 选择目标平台。
- 自动生成各平台草稿。
- 校验平台字段完整性。
- 人工审核 Hook。
- 模拟发布。
- 发布结果报告。

### 暂不支持

- 真实账号登录。
- Cookie 自动读取。
- 绕过平台风控的自动发布。
- 复杂多轮 Agent 循环。
- 完整的图片或视频编辑器。

## 成功标准

- 用户只输入一次内容，就能生成多个平台版本。
- 每个平台输出结果有明显平台差异。
- Workflow 每个节点可独立测试。
- 新增平台不需要修改主流程。
- README 能说明依赖、核心模块和扩展方式。
